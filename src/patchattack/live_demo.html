Does it also fool a modern reasoning model?

The classifiers above are the patch’s home turf. The harder question: does the same sticker fool a current vision-language model that reasons about the scene — and that was never trained against the patch? We tested Qwen2.5-VL-3B, asking only “What is the main object? One word.”

Evidence measured live on a Colab A100 · model Qwen/Qwen2.5-VL-3B-Instruct (bf16) · patch physical_banana, never in the model’s training loop · deterministic greedy decode.

The honest finding. A patch optimized only against older CNNs and CLIP/SigLIP still hijacks a newer model it never saw — a real cross-model transfer, and on a reasoning model at that. The two hold-outs are the interesting part: images with one big, unambiguous, centered object (a golf ball filling the frame, a chainsaw) sometimes let the VLM’s reasoning win, and growing the patch doesn’t force it. So the claim is “most images → banana, every embedding model → banana” — not a magic 100%. That gap between pattern-matching and reasoning is exactly what’s worth showing.
